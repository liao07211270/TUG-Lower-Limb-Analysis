## 舊版設定（與最終版不同之處）
- 取樣率 128Hz；時間換資料點乘 128
- 視窗大小比較 32／48／64／96；**步長（SP）固定 60 點**（原 README 稱「重疊率」，實際為步長；WS 小於步長時視窗之間有空隙）
- 第 6 項特徵為變異數（最終版為 jerk 標準差）
- Random Forest 200 棵；同時比較 AdaBoost 與 Decision Tree
- 中位數濾波 31 點；後處理門檻為 128Hz 版（碎片 250 點、強制轉身 110 點、坐下 180 點…）

## 舊版結果（Random Forest，視窗 48）
| 指標 | 數值 |
|---|---|
| Accuracy | 90.91% |
| Sensitivity | 85.44% |
| Precision | 86.12% |
| F1-Score | 0.845 |

> 視窗 48 與視窗 64 的 Accuracy 約 90.9% 與 90.6%，差異不大；視窗 32 的表現明顯較低，
> 但因步長固定為 60，視窗大小與涵蓋範圍同時改變，不能單獨解讀為視窗大小的影響。
